* **PCAP Analysis:** Capturing and dissecting traffic in Wireshark - spotting anomalies, identifying lateral movement patterns, flagging IOCs.
* **Log Review:** Working through SOC alert triage workflows - distinguishing signal from noise, building detection logic, practicing escalation decisions.
* **Web App Hunting:** SQL Injection, XSS, SSRF on PortSwigger Web Security Academy. Hands in the machine, not the textbook.
* **Network Recon:** Nmap scanning, enumeration, and AD attack path analysis in controlled lab environments.
* **Exploitation & Post-Exploitation:** Privilege escalation with LinPEAS, HTTP interception with Burp Suite, payload delivery with Metasploit.
